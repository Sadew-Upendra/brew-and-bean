# Brew & Bean ☕

A clean and responsive coffee shop website built with **HTML, CSS, and JavaScript**.

## Overview

Brew & Bean is a modern coffee shop website featuring a simple layout for showcasing coffee, food, prices, special offers, and contact information.

## Features

* Responsive design for desktop, tablet, and mobile
* Coffee shop menu with images and prices
* Popular items section
* Price table
* Special offer interaction with JavaScript
* CSS animations
* Contact and social media links

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
brew-and-bean/
├── index.html
├── style.css
├── script.js
└── images/
```

## Preview

Open `index.html` in any modern web browser to view the website locally.
